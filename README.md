Focus-Gate: Bio-Digital-Health 

Welcome to the > Focus-Gate Protocol < an open-source, socio-technological ecosystem connecting canine cognitive health, neurodivergent human support (ADHD – Attention Deficit Hyperactivity Disorder), and cutting-edge Edge-AI. 

Our mission is to translate multi-modal biological data into actionable, everyday interventions.  

We utilize the principle of "Fördern durch Fordern" (Challenge to Cherish) to reactivate the Locus Coeruleus, protect the blood-brain barrier (Claudin-5), and combat neuroinflammation in both humans and animals. 

This repository is more than code > it is a living blueprint for systemic resilience.

The Vision & Social Impact:

This project is built on three pillars of absolute accessibility, evolutionary symbiosis, and systemic inclusion: 

1. Open-Source Software & Hardware: Fully accessible blueprints to prevent corporate gating or patent-trolling. Anyone can build, fork, and improve this system. 

2. Inclusive Production (WfbM): The physical hardware matrix is designed to be manufactured by sheltered workshops for people with disabilities (Behindertenwerkstätten / WfbM), combining tangible social impact with high-quality, sustainable local production. 

3. Translational Co-Regulation: A unique bond-building protocol where a neurodivergent handler (ADHD – Attention Deficit Hyperactivity Disorder) and a cognitive-declining pet (Dementia/Hearing Loss) train together, co-regulating their nervous systems through the same evolutionary conserved pathways. 

System Architecture Focus-Gate bridges macro-behavioral interaction with micro-molecular research:
 
Hardware Specification: The "Sniff & Catch" Matrix 

The physical training core is a 3x3 modular board designed for easy CNC milling and assembly in sheltered workshops: 

Microcontroller: ESP32 / Raspberry Pi 4 (Wi-Fi & Bluetooth enabled).  

Sensors: 9x Capacitive Touch-Sensors behind an easy-to-wipe front plate. 

Visual Stimuli: 9x RGB-LED Rings for high-contrast tracking (essential for dogs with hearing loss). 

Olfactory Stimuli: 4x Low-noise 12V Micro-Solenoid Valves connected to medical-grade scent cartridges (e.g.: Chamomile, Peppermint) triggered by an internal silent micro-compressor. 

Software Stack & AI Integration 

Gemma 4 (E4B): Runs natively on-device (Edge-AI) via the handler's smartphone/tablet/MiniPC. It analyzes real-time video streams for Pupillometry (tracking Locus Coeruleus activation) and automatically scales game difficulty to prevent tonic overstimulation. 

AlphaFold 3 Pipeline: Used in the backend to model how specific nutraceuticals prevent the enzymatic degradation of Claudin-5.
